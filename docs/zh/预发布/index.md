# 三欲动力学模型 | Three Desires Dynamics Model

三欲动力学模型的目的，是通过区分三欲，以动力学的角度理解生活中的欲望、感受和行为怎样形成与变化，并帮助人更清晰地生活。

## 简介

三欲动力学模型把人的欲望主要区分为三类：

- **身体欲望**，简称**性欲**
- **掌控欲望**，简称**情欲**
- **他利欲望**，简称**爱欲**

在人类范围内，“身体欲望、掌控欲望、他利欲望”是更准确的称呼；“性欲、情欲、爱欲”主要作为不会引起歧义时使用的简称。

模型把**欲望**看作从复杂状态中抽取出来的、与有意识行为形成直接相关的抽象动力概念。人的状态形成欲望，欲望在状态条件下形成有意识行为；行为与其他现实过程共同造成实际变化，主体从实际变化中形成实际感受结构，并继续更新状态和之后的欲望。

三类欲望主要根据**满足依赖什么结构**区分：

- **身体欲望**：满足依赖主体自身实际状态变化，不能仅由意识确认替代；满足本身不增殖，相关身体状态重新形成后可以再次形成相似欲望。
- **掌控欲望**：满足可以仅通过主体内部意识结构变化完成；掌控欲望的满足与增殖具有双向对应关系。
- **他利欲望**：满足依赖相关他利态发生相应变化，并在主体侧形成满足性状态变化，不能仅靠主体内部单方面确认完成。

模型不根据一个人做了什么，就直接判断他有什么欲望。相同欲望在不同状态下可以形成不同有意识行为，一个行为也可以同时受到多个相互独立的具体欲望推动。

在此基础上，模型进一步分析掌控欲望的**增殖、衰退、强化和代偿**，以及反刍、泛化、转化、回避与去激活等复合和长期变化。其中，转化不只是降低掌控欲望，而是欲望形成及其相互关系所依赖的长期状态结构发生相对稳定的重组。

这个模型不是人格分类，也不把三种欲望划分为不同的道德等级。它目前是一套基于常识观察建立的**定性解释性模型**，主要关注内部一致性、概念边界和现实分析能力。

在可见未来内，本项目**不承诺自行完成统一量化、完整数学建模或系统性实验操作化**。

目前为 **6.6 版本**，后续计划添加英文翻译版本。
